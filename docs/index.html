Once a second real dataset (healthcare access — nearest hospital by drive time) got built the same way inside that project, the shared shape between the two became clear enough to actually generalize — rather than guessing at an abstraction from a single case.

The interface

Add a dataset by implementing one small contract

Every dataset — no matter how different its underlying data looks — implements the exact same shape: a fixed list of layers, an optional list of real years it has history for, and a lookup that returns a 0–100 value on a shared "higher = more concerning" scale, plus a one-line human-readable detail.

// lib/datasets/types.ts
interface Dataset {
  id: string;
  label: string;
  layers: DatasetLayer[];
  supportsTime: boolean;
  availableYears?: number[];  // real years only, e.g. crime's [2020..2024]
  getValue(cityId, layerId, context?): {
    value: number;   // 0-100, higher = more concerning
    detail: string;  // "72/100, high" or "Bellevue Hospital, 4 min"
  } | null;         // null = a real gap, never a fabricated value
}

That's it. Implement getValue, register the dataset once, and the exact same MultiLayerMap/AddLayerPanel components render it — continuous gradient, click-to-select detail panel, legend, a year control if it has real history, all of it — with zero new rendering code. Any number of layers from any number of datasets can be active on the map at once, each stacked as its own gradient (allergy-locator's proven stacked-opacity pattern, generalized across datasets instead of just allergens).

What's real today

Proven with twelve genuinely different real implementations

All free, all keyless, across the full 512-city spine — every one of them ships its own methodology doc naming its real sourcing and honest gaps.

Allergy severity live

Ported from Allergy Locator's own validated grass ground-truth (MAE 2.3) plus 28 modeled allergens.

Crime live

Real violent- and property-crime rates from the FBI Crime Data Explorer, with genuine 2020–2024 year-by-year history.

Care access live

Nearest hospital by drive time — general, pediatric specialty, and pediatric cardiac surgery.

Natural hazard risk live

FEMA National Risk Index — overall plus inland flood, coastal flood, and wildfire sub-scores.

Social vulnerability live

CDC/ATSDR SVI composite plus its 4 sub-themes, at census-tract resolution.

Health outcomes live

CDC PLACES chronic-disease prevalence — asthma, obesity, diabetes, depression, high blood pressure.

Food access live

USDA Food Access Research Atlas — share of a population living far from a supermarket.

Housing supply & speed live

Zillow's own For-Sale Inventory and Mean Days to Pending — how tight and how fast the local market is.

Traffic safety live

Motor-vehicle crash death rate — County Health Rankings, sourced from real NCHS/NVSS mortality data.

Transit access live

FTA National Transit Database service level, joined by a real Census Urban Area ID crosswalk.

Stack any number of layers live

Add a layer, then another, then more — each renders as its own gradient on one shared map, with a click-to-detail panel listing every active layer's value for that city.
